# 关键页面响应式视觉验收清单

本清单用于手工验收关键工具页在 360px、768px、1280px 三个断点下的可读性与交互稳定性。

## 页面范围
- DNA 密码翻译器（`/bio/dna-translator`）
- 星球宜居性评分器（`/bioastro/habitability`）

## 360px（移动端）
- 页面左右内边距保持一致，无贴边文本。
- 顶部标题、卡片标题不换行截断。
- 底部导航不遮挡主按钮与结果文本（可滚动到最底部完整查看）。
- DNA/mRNA 长序列支持横向滚动或断行展示，不出现内容被裁切。
- JSON 文本输入区可以完整粘贴长文本并保留换行。

## 768px（平板）
- 卡片布局与间距均匀，操作按钮不重叠。
- 工具页输入区与结果区可保持单列或双列过渡时无跳动。
- 长文本区域在滚动与断行策略下保持可读。
- 页面底部留白充足，底部导航不覆盖内容。

## 1280px（桌面）
- 工具页在大屏使用双栏布局（信息区 / 结果区）显示，不出现过宽文本行。
- 主容器最大宽度统一，内容视觉中心稳定。
- 卡片高度差异不会导致操作区错位或挤压。
- 长 JSON 与长序列在桌面宽屏下仍可复制、阅读、滚动。

## 通用回归项
- 路由切换后滚动与布局正常，无闪动与遮挡。
- localStorage 读取优先级行为不受样式改动影响。
- `npm run build` 通过，无 TypeScript 报错。
